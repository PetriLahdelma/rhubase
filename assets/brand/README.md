# Brand assets

The preferred RhuBase direction uses a visible gap between the rhubarb strokes. Use the [user-supplied gap variations](rhubase/gap-variants/README.md) for future web development. Variation 1 is the recommended unboxed starting point; variation 3 is a badge treatment. The user expressed a preference for the gap, without selecting one specific variation as the final master.

The earlier [solid-junction SVG](rhubase/rhubase-logo.svg), `rhubase-v1/`, and `rhubase-v1.zip` remain reference material. Use the supplied gap vectors as the starting point for new assets.
