# RhuBase gap variations

The user prefers a visible gap between the rhubarb strokes. Preserve that negative space in future brand work. These three supplied SVGs were copied byte-for-byte on 2026-10-06, retaining their creator attribution. No single variation has been selected by the user as the final master.

| File | Treatment | Suggested use |
| --- | --- | --- |
| [rhubase-gap-1.svg](rhubase-gap-1.svg) | Unboxed mark and outlined wordmark; no background rectangle | Recommended starting point for headers and general web use |
| [rhubase-gap-2.svg](rhubase-gap-2.svg) | Similar lockup with an explicit pale gray rectangle | Light-background presentation treatment |
| [rhubase-gap-3.svg](rhubase-gap-3.svg) | Compact lockup inside a pale green rounded rectangle | Badge or contained brand treatment |

All three contain the wordmark without a tagline. When a tagline is needed, the agreed wording is **Many systems. One foundation.**

## Web integration

- Each source has an `80 × 80` canvas with substantial vertical space around the horizontal artwork. Prepare a tightly framed derivative for compact placement instead of changing these supplied originals.
- Versions 2 and 3 include background shapes; they are not background-free marks.
- Keep a visible gap when deriving small-size or monochrome symbols. Their actual minimum usable size remains to be tested.
- The lettering is outlined and needs no external font. Use accessible image text such as `alt="RhuBase"` when embedding the logo.
- Preserve each version's supplied colors until a single palette is finalized.

## Verification and provenance

The files parse as SVG XML and contain only static paths and, in versions 2 and 3, a rectangle. No scripts, external resource references, or embedded raster images were found. Native Quick Look renders of all three were inspected to compare the gap and background treatments; this was not a favicon-size test.
