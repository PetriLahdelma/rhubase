Status: Preparation only; no baseline run has occurred. The controlled fixtures are development material, not a blind evaluation corpus.

Use a newly registered real consumer before scoring product advantage. If this fixture is used for a smoke comparison, report it separately and disclose that the Shift implementation was built around it.

## Candidate task

Consolidate the selected application's Commerce and Admin component usages into the provided Foundation target. Preserve form-submit behavior, navigation destinations, link semantics, and selected state. Apply the approved target focus treatment while preserving spacing. Preserve loading usages where the target lacks an approved equivalent. Leave opaque runtime-prop usages unresolved and explain why. Keep untouched behavior and source-system dependencies needed by retained usages.

Supply the agent with a clean consumer, source and target definitions, a human-readable approved mapping brief, available ordinary tests and upstream documentation. Permit reusable instructions, scripts, and a local decision ledger. Do not supply Shift's `after` texts, patch files, generated candidate, result report, or hidden evaluator oracle. A separate evaluator must retain the expected results.

## Before running

- Pin the real corpus, agent/model/tool versions, approved input context, time/call/cost budgets, and acceptance rubric.
- Select a fresh workspace. Do not give an unrestricted agent access to hidden oracle or Shift output directories.
- Record first-use setup, mapping authoring, supervision, review, corrections, and coordination independently of execution time.
- Reuse the resulting DIY artifacts on a second consumer. Do not make the baseline restart unnecessarily.
- Introduce one revised shared decision and one advanced consumer revision; observe invalidation and repeat work.
- Review both arms at equal completed scope and quality. No product conclusion from synthetic fixtures alone.

No external agent process was launched in this spike. Persisted native subagents could not be reopened because the required tool was unavailable; no substitute independent review is claimed.
