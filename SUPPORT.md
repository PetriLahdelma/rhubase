# Support

RhuBase is a community alpha without a hosted support service or response-time commitment.

## Start here

1. Read [Getting started](docs/getting-started.md) and [Troubleshooting](docs/troubleshooting.md).
2. Check the [current validation status](docs/validation.md) and known limitations.
3. Search existing [GitHub issues](https://github.com/PetriLahdelma/rhubase/issues).
4. If the problem is new, use the repository [issue chooser](https://github.com/PetriLahdelma/rhubase/issues/new/choose).

For useful help, include macOS and architecture, `node --version`, `rustc --version`, `./bin/rhubase --version`, a sanitized command and error, and a minimal synthetic fixture when possible.

Do not post customer repositories, credentials, access tokens, internal URLs, or personal data.

## What support covers

Community support focuses on installation, the read-only `assess` and `infer` commands, report interpretation, reproducible discovery gaps, and contributions to the documented boundary.

Historical migration demos, autonomous editing, real application migration, hosted deployment, organization integrations, and unpublished future roadmap items are not supported product features.

Report security vulnerabilities privately using [SECURITY.md](SECURITY.md).
